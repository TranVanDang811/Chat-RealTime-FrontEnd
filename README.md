### Features

- Authentication (JWT)
- Realtime messaging
- Private & Group chat
- Notifications
- AI chat summary
- Profile & avatar
- Friend system

### Tech Stack
- ReactJS
- Redux Toolkit
- Axios
- WebSocket (STOMP)
- TailwindCSS

## WebSocket

### Connect
- ws://localhost:8080/ws

### Subscribe
- /topic/room/{roomId}
- /user/{userId}/queue/messages
- /user/{userId}/queue/summary

### Send
- /app/chat.send
- /app/chat.summarize
